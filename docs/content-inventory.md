## Publication gate

Before a file enters this repository it must pass:

1. provenance and ownership review;
2. privacy and synthetic-data review;
3. SPDX license declaration;
4. search for KDL IDs, donor names/slugs, Kodama service names, fixture paths,
   credentials, and private hostnames;
5. independent review of generated source and packaged artifacts.
